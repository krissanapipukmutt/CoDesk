# Glossary

| คำศัพท์ | ความหมายเชิงโครงการ |
|---|---|
| CoDesk / co_desk | ชื่อโครงการและชื่อ schema หลักใน PostgreSQL |
| Short Paper | เอกสารวิชาการที่ครอบคลุมบทที่ 1–3 ในเฟสปัจจุบัน |
| Database-First | แนวทางที่เริ่มจากออกแบบ schema/constraints/relationships ก่อนเขียนโค้ด |
| ERD (Entity-Relationship Diagram) | แผนภาพความสัมพันธ์ระหว่างเอนทิตีในฐานข้อมูล |
| Entity | หน่วยข้อมูลเชิงธุรกิจ เช่น ผู้ใช้ องค์กร พื้นที่ โต๊ะ การจอง |
| Attribute | คุณลักษณะของ entity เช่น ชื่อ รหัส สถานะ เวลาเริ่ม |
| Relationship | ความสัมพันธ์ระหว่าง entity เช่น 1:N หรือ N:M |
| PK (Primary Key) | คีย์หลักที่ระบุแถวข้อมูลแบบไม่ซ้ำ |
| FK (Foreign Key) | คีย์อ้างอิงไปยังตารางอื่นเพื่อคงความถูกต้องของข้อมูล |
| Constraint | กฎบังคับข้อมูล เช่น NOT NULL, UNIQUE, CHECK |
| RLS (Row-Level Security) | กลไกควบคุมสิทธิ์ระดับแถวของ PostgreSQL/Supabase |
| Supabase Auth | ระบบยืนยันตัวตนผู้ใช้ที่ผูกกับฐานข้อมูล Supabase |
| Traceability | การเชื่อมโยง requirement ไปยังเอกสาร/ผลลัพธ์ที่เกี่ยวข้อง |
| Requirement Verbatim | การบันทึก requirement ต้นฉบับแบบไม่ย่อและไม่แก้ถ้อยคำ |
| Tech Stack | ชุดเทคโนโลยีหลักของระบบทั้ง frontend/backend/database |
| FullCalendar | ไลบรารีปฏิทินสำหรับแสดงและจัดการข้อมูลการจองตามเวลา |
| TanStack Table | ไลบรารีตารางข้อมูลสำหรับรายงานเชิงโต้ตอบ |
| Recharts | ไลบรารีกราฟสำหรับแสดงผลเชิงสถิติ |
| dayjs timezone | ไลบรารีจัดการวันเวลา/เขตเวลา (ใช้ Asia/Bangkok) |
| Handoff | เอกสารส่งต่องานให้ผู้ปฏิบัติงานคนถัดไปทำต่อได้ทันที |
